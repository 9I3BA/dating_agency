# Информационная система «Брачное агентство» (Dating Agency)

Данный проект представляет собой консольное (или оконное) приложение на Python, разработанное в рамках курсового проекта. Система предназначена для автоматизации работы брачного агентства: регистрации пользователей, управления анкетами, хранения фотографий и поиска партнеров по заданным критериям.

## Основные функции
* **Управление пользователями**: Регистрация, авторизация и редактирование личных анкет.
* **База данных**: Хранение всей информации о клиентах (логины, пароли, предпочтения) в локальной БД SQLite (`users.db`).
* **Работа с медиа**: Возможность привязки и хранения фотографий пользователей в структурированной папке `photos`.
* **Умный поиск**: Подбор кандидатов на основе фильтров (возраст, город, интересы и др.).

## Структура репозитория
* `code.py` — основной исполняемый файл приложения с логикой программы.
* `users.db` — база данных SQLite, содержащая таблицы пользователей и их анкет.
* `photos/` — директория для хранения загруженных фотографий пользователей.
* `Документация к курсачу.zip` — архив с пояснительной запиской, схемами БД и техническим заданием.
* `output.zip` — скомпилированная версия или резервная копия выходных данных проекта.

## Как запустить проект локально

### 1. Клонирование репозитория
Откройте терминал, перейдите в рабочую директорию и скачайте репозиторий:
```bash
git clone https://github.com
cd dating_agency
```

### 2. Подготовка окружения
Убедитесь, что у вас установлен Python версии **3.8 или выше**. Специальных сторонних библиотек для стандартной работы со встроенной БД SQLite не требуется, однако если в коде используются внешние зависимости (например, `Pillow` для обработки фото), установите их:
```bash
pip install -r requirements.txt
# Или вручную, если зависимости не описаны:
# pip install Pillow
```

### 3. Запуск программы
Запустите главный скрипт через терминал:
```bash
python code.py
```
